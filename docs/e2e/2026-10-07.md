## What they found

- **A push left to nobody.** A session that dies between the commit of `conformant` and its push is taken up by no relaunch: `/surface-execute` finds no plan once the only one of the branch is over, and stops before any push. The scenario fails by construction and is marked as expected to fail until the chain takes that push up.
- **A line of attribution under the description of a draft pull request**, once in the seven openings these runs made: the session wrote the output of `surface-status pr-body` to a file, then gave `gh` that file and a line of its own. The six others gave the output of the script and nothing else.
- **A scenario that passed by luck.** The kill of a session in a slice waited for code not yet committed, looked for every 2 seconds. In one run both executors wrote, tested, recorded and committed in one command, and the session reached `conformant` without being killed. The toy can now be built with a slow test, which keeps that code uncommitted for 20 seconds.

## What these runs do not say

- How often a scenario fails for a path a model takes: one run each.
- A session killed between a record and its commit, or between a commit and its push. An agent chains the two in one command and leaves no moment to kill it at: those paths start from a state prepared as such a death leaves it.
- A break an executor suspects on its own. No plan made one suspect reliably: the two scenarios start from the suspicion recorded and the work left unfinished, and what the reviewer then says is a model's judgement, confirmed once and dismissed once.
- GitHub. The pull request steps are played against the stand-in `gh` of the image.
- The prompts as they stand after this day: the extractor and the hand over of `/surface-plan` changed since these runs. No scenario asserts what either says.
- The helpers as they stand after the review of these scenarios, on 2026-10-08: the look at a running session takes no lock in its repository, the watch that kills a session kills it whatever it raises, and the kill in a slice is played by that watch. That scenario alone was played again, on the prompts of commit `505848a`: passed, 0.43 USD for the session that took over.
